# EasyBrowser Config Shape

Current config skeleton is intended to cover:

- API listen settings
- provider enable / disable flags
- strategy defaults
- direct-mode guardrails
- process spawn limits
- per-provider max runtimes
- cooldown thresholds
- stats retention or sampling policy
- Browserbase credentials reference points

Template files live under:

- `config/templates/`

Schema notes live under:

- `config/schema/`
